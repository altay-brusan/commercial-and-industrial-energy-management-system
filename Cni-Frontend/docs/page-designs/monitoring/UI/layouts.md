## CSS Grid Definitions

```css
/* Overview Page */
.monitoring-overview-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 24px;
}

@media (min-width: 768px) {
  .monitoring-overview-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1024px) {
  .monitoring-overview-grid {
    grid-template-columns: repeat(4, 1fr);
  }
}

/* Live Data Page */
.live-data-container {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

.live-data-table {
  overflow-x: auto;
}

/* Power Flow Page */
.power-flow-diagram {
  aspect-ratio: 16/9;
  min-height: 400px;
}

.power-flow-cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}

/* Grid Status Page */
.grid-status-metrics {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 24px;
}

@media (max-width: 768px) {
  .grid-status-metrics {
    grid-template-columns: 1fr;
  }
}
```

## Breakpoints

| Breakpoint | Min Width | Columns | Notes |
|------------|-----------|---------|-------|
| Mobile | 0px | 1 | Stacked, simplified |
| Tablet | 768px | 2 | 2-column grid |
| Desktop | 1024px | 4 | Full layout |
| Large | 1440px | 4 | Expanded spacing |
| XLarge | 1920px | 4+ | Max content width |
