## Breakpoints

| Breakpoint | Min Width | Columns | Layout |
|------------|-----------|---------|--------|
| Mobile | 0px | 1 | Stacked |
| Tablet | 768px | 2 | 2-column grid |
| Desktop | 1024px | 4 | Full layout |
| Large | 1440px | 4 | Expanded spacing |

## CSS Grid Tanımları

```css
/* Mobile */
.dashboard-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* Tablet */
@media (min-width: 768px) {
  .dashboard-grid {
    grid-template-columns: repeat(2, 1fr);
    gap: 20px;
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .dashboard-grid {
    grid-template-columns: repeat(4, 1fr);
    gap: 24px;
  }
}
```
